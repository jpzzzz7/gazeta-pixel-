Guia para iniciantes

Glossário gamer

  • NPC: personagem controlado pelo jogo.
  • RPG: jogo em que você evolui um personagem.
  • Skin: visual diferente para um personagem.
  • Speedrun: terminar o jogo no menor tempo possível.

Como escolher sua plataforma

Não existe plataforma certa para todo mundo. A melhor é a que cabe no seu bolso e tem os jogos que você quer jogar.

  1. Veja quanto você pode gastar.
  2. Confira em quais plataformas saem os jogos que você quer.
  3. Pense se vai jogar mais em casa ou fora de casa.

Celular é o jeito mais barato de começar. Console é o mais simples de usar na TV. PC é o mais flexível, mas costuma custar mais.

Kit básico

  • Controle ou teclado e mouse
  • Fone de ouvido
  • Internet estável
  • Cadeira confortável

Quem faz a Gazeta

A Gazeta Pixel é um projeto de três estudantes de Desenvolvimento Front End. Cada um cuidou de uma parte do portal:

  • Santiago: cabeçalho, menu, banner, guia para iniciantes, personalização visual, equipe e rodapé.
  • João Victor: notícias, reviews, carrossel de capas, galeria e adaptação para telas pequenas.
  • João Pedro: ranking, criador de personagem com janela modal e formulário de inscrição.
