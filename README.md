# 🎮 Gazeta Pixel

Portal One Page sobre games, desenvolvido em trio com HTML, CSS e JavaScript puros para a disciplina de Desenvolvimento Front End (ADS).

## 📌 Sobre o projeto
Página única que reúne conteúdo sobre o universo dos games, com ranking, criador de personagem e formulário de inscrição.

## 🛠️ Tecnologias
- HTML5
- CSS3
- JavaScript (sem bibliotecas ou frameworks)

## ✨ Funcionalidades
- **Ranking**: tabela de classificação com 10 linhas e 6 colunas
- **Criador de personagem**: personalização com janela modal
- **Formulário de inscrição**: com validação dos campos
- [outras seções feitas pelos colegas]
